# 🚀 Как поступить в школу

![SCHOOL](assets/images/kazanSchool.png)

Пройти в школу может каждый, действительно и абсолютно точно каждый, есть только разумные ограничения в возрасте (необходимо быть совершеннолетним).

Утверждается, что знаний никаких быть не должно, однако, вам необходимо уделить хотя бы 2-3 дня перед стартом обучения для набора каких-то стандартных навыков или молиться что будет "паровоз" - участник интенсива который будет помогать вам со всеми вашими проблемами и натянет ваши пробелы, которые образовались потому что опыт абсолютно нулевой.

Сначала мы попадаем на 26 дней первогоначального обучения, в нем мы показываем свое искреннее желание учиться и обучаться, грубо говоря некий отбор который легко пройти, если ты не забиваешь, проходит около 25% интенсива, те самые 75% это те кто отвалились после очередного экзамена или изначально пошли по приколу.
