# ⚡ Полезные команды для участников интенсива

## 🖥️ Базовые команды терминала

### Навигация по файловой системе
```bash
ls -la          # Показать все файлы и папки с подробной информацией
cd <папка>      # Перейти в папку
pwd             # Показать текущий путь
cd ..           # Перейти на уровень выше
cd ~            # Перейти в домашнюю папку
```

### Работа с файлами
```bash
cat <файл>      # Показать содержимое файла
less <файл>     # Просмотр файла с прокруткой
head <файл>     # Первые 10 строк файла
tail <файл>     # Последние 10 строк файла
grep "текст" <файл>  # Найти текст в файле
```

### Компиляция C
```bash
gcc -Wall -Wextra -Werror <файл.c> -o <программа>  # Компиляция с флагами
./программа     # Запуск программы
bash name.sh    # Запуск программы
sh name.sh      # Запуск программы
gcc -g <файл.c> -o <программа>  # Компиляция для отладки
```

## 🔧 Git команды для интенсива

### Основные команды
```bash
git clone <ссылка>    # Клонировать репозиторий
git status           # Статус репозитория
git add .            # Добавить все изменения
git commit -m "сообщение"  # Создать коммит
git push            # Отправить изменения
```

### SSH ключи
```bash
ssh-keygen -t rsa -b 4096  # Создать SSH ключ
cat ~/.ssh/id_rsa.pub  # Показать публичный ключ
```

## 🐛 Отладка и проверка памяти

### Valgrind (Linux/Ubuntu)
```bash
valgrind --leak-check=full --show-leak-kinds=all ./программа
```

### Leaks (macOS)
```bash
leaks -atExit -- ./программа
```

## 📝 Работа с текстовыми редакторами

### Vim базовые команды
```
i        # Режим вставки
Esc      # Выйти из режима вставки
:w       # Сохранить
:q       # Выйти
:wq      # Сохранить и выйти
:q!      # Выйти без сохранения
dd       # Удалить строку
yy       # Копировать строку
p        # Вставить
```

## 🔥 Лайфхаки для интенсива

### Быстрая проверка кода
```bash
# Создать alias для быстрой компиляции
alias cc='gcc -Wall -Wextra -Werror'
cc main.c -o test && ./test
```

### Проверка стиля кода
```bash
python3 cpplint.py --extensions=c *.c
```

### Массовая компиляция
```bash
# Компилировать все .c файлы
for file in *.c; do gcc -Wall -Wextra -Werror "$file" -o "${file%.c}"; done
```

## 🧹 Очистка места на школьном iMac

**Скачай и запусти:**
```bash
# Скачать скрипт
curl -O https://raw.githubusercontent.com/vashking/school21_helper/restructure-test/docs/faq/useful-commands/clean.sh

# Дать права на выполнение
chmod +x clean.sh

# Запустить очистку
./clean.sh
```

**Или скопируй файл [clean.sh](clean.sh) из этой папки**

### Что делает скрипт:
- 🗑️ Очищает все кеши браузеров (Chrome, Safari, Firefox)
- 🗑️ Удаляет кеши VS Code, Slack, Telegram
- 🗑️ Чистит системные кеши macOS
- 🗑️ Удаляет временные файлы и логи
- 🗑️ Очищает корзину и Docker кеши
- 🗑️ Удаляет файлы .DS_Store
- 📊 Показывает освободившееся место

### ⚠️ Важные моменты:
- Скрипт **безопасен** - удаляет только кеши и временные файлы
- **НЕ удаляет** твои проекты и важные данные
