# 🎯 Ультимативный гайд на прохождение интенсива

## 🗓️ До интенсива (за неделю)

### Техническая подготовка
- [ ] **Изучить базовые команды терминала** (ls, cd, mkdir, rm, chmod)
- [ ] **Настроить Git и SSH ключи** для GitHub
- [ ] **Изучить основы C** (переменные, циклы, функции, массивы)
- [ ] **Решить 10-15 простых задач** на Codewars/HackerRank
- [ ] **Попрактиковаться с gcc** и флагами компиляции

## 📅 Первая неделя (дни 1-7)

**Стратегия:**
- Не паникуй, если что-то не понимаешь
- Найди "паровоза" - опытного участника
- Активно общайся с соседями по компьютеру
- Записывай полезные команды
- Сосредоточься на понимании, а не на скорости
- Используй отладчик для понимания кода
- Не стесняйся переспрашивать

**Чек-лист:**
- [ ] Настроить рабочее окружение на iMac
- [ ] Склонировать репозиторий с заданием
- [ ] Выполнить все задания по bash
- [ ] Закоммитить и запушить решения
- [ ] Разобраться с типами данных
- [ ] Освоить ввод-вывод (scanf, printf)
- [ ] Понять условные конструкции
- [ ] Научиться работать с циклами

## 🚨 Красные флаги (чего НЕ делать)

### ❌ Технические ошибки
- Не игнорируй предупреждения компилятора
- Не забывай освобождать память
- Не копируй код не понимая его
- Не откладывай задания на последний день
- Не пропускай проверку на утечки памяти

### ❌ Социальные ошибки
- **НЕ РУГАЙСЯ** ни с кем (это критично!)
- Не жалуйся на других участников ADM и не создавай токсичную атмосферу в команде, в конце интенсива вы оцениваете друг-друга и какой-нибудь дурачок может тебе очень сильно запоганить ситуацию :)
- Не игнорируй групповые проекты
- Не изолируйся от сообщества

### ❌ Психологические ошибки
- Не паникуй при первых неудачах
- Не сдавайся после плохого экзамена
- Не пренебрегай сном и едой
- Не ставь нереалистичные цели
- Не забывай про жизнь вне школы

## 🏆 Критерии успеха

### Минимум для прохождения
- [ ] Пригнать на 3/4 экзамена (хотя бы приходить)
- [ ] Участвовать во всех групповых проектах
- [ ] Закоммитить большинство ежедневных заданий (не значит выполнить)
- [ ] Не получить негативных отзывов от других участников

### Максимум для гарантированного прохождения
- [ ] Сдать все экзамены на высокий балл
- [ ] Быть активным участником команды в групповых проектах
- [ ] Помогать другим участникам
- [ ] Участвовать в жизни школы (мероприятия, общение)
- [ ] Показать стабильный прогресс
