# Введение #

В данный момент обучение занимает 26 дней. За 2-3 дня до начала обучения вам приходит письмо, в котором описаны подробности, например, ваш логин для авторизации в школе и прочее. По нему, вы кстати, сможете зайти еще до начала обучения если пойдете [по какой-то ссылочке](https://edu.21-school.ru/), мало чего сможете добиться, но уже сможете познакомиться с платформой, записаться на различные мероприятия (за что вам дадут достижение в честь первого мероприятия датой раньше, чем начинается сам интенсив)

Каждая неделя - максимально циклична. 
Кампус работает круглосуточно, соответственно выполнять задания вы сможете когда угодно, кроме пятницы, субботы и воскресенья, но об этом позже.

С понедельника по четверг вы выполняете индивидуальные задания. Индивидуальные - не значит что они для каждого свои, как раз таки задания на протяжении ВСЕГО обучения общие, но выполняет их каждый сам за себя. О типаже заданий вы узнаете чуть позже.

Пятница - день экзамена, день не очень приятный, вам необходимо покинуть кампус до 10-11 дня, чтобы к 12-13 вернуться в кампус на экзамен. Вы складываете телефоны, часы и прочие акссесуары в конверт, не достаете их на протяжении всего экзамена и решаете задачи, которые вам выдают [на одном неизвестном сайте](exam.21-school.ru). Задачи не представляют из себя ничего сложного, по сути облегченные задачи из того что вы решали на протяжении всей недели.

По окончанию экзамена (в районе 6-7 вечера), вы можете приступать к групповому заданию запланированному по большей части на субботу-воскресенье. На платформе [edu](https://edu.21-school.ru/) вы получите свою рандомную команду из 3 человек, тебя и еще 2 рандомных ребят. Так же выбирается рандомно и тимлид, который по сути должен регулировать ваши действия и принимать участие в работе с вами, но на практике - молитесь чтоб он вообще не забил на школу к этому моменту.

Теперь поподробнее к тому, как именно будут проходить дни и что за тематика там будет:

# 1. День #1 #
Первый день максимально простой, но может пройти немного в стрессе из-за непривычной обстановки. Авторизуйся в аккаунт, настрой iMac под свои удобства, скачай телегу, поставь кота на рабочий стол, авторизуйся в яндех музыке, поменяй настройки под себя, например на русский язык, после чего приступай к задаче. Еще лучше, если пока ты сидишь над задачей, временами ты ходишь к другим ребятам и общаешься с ними, ничего важнее чем социальные навыки, коммуникация и респект от людей вокруг на интенсиве не будет.

Навыки которые тебе понадобятся в первый день:
- Git, нужно понимать как авторизоваться, вписать свой SSH ключ в GitLab, склонировать репозиторий с задачей с помощью терминала. git clone, git checkout, git branch, git commit, git push.
- Bash, понадобятся ls, cat, sh, tail, wc, mkdir, rm, chmod, ps, kill, top/htop

# 2. День #2 #
Второй день тоже максимально простой, затрагивает только bash тематику, никакого кодинга, но может быть уже чуть-чуть посложнее.

Навыки которые тебе понадобятся:
- Базовое владение vim, i, :wq, dd, yy, p, /, n, G, gg, :set
- Базовое написание bash скриптов, условия, циклы, ввод/вывод, $?, переменные, chmod +x
- grep, awk, cut, sort, uniq, tail, journalctl, dmesg
- git merge, git rebase, git HEAD, <<<<, >>>>, git mergetool, git commit, git push, git clone.

# 3. День #3 #
Третий день - это боевое крещение по СИ (C): ввод-вывод, арифметика, сравнение, условия, типы данных и борьба с float-точностью. Всё строго на C

Навыки: Ввод/Вывод, арифметика, условия (if/else), типы данных (int, float, double), функции из math.h, компиляция gcc, базовый синтаксис СИ.

# 4. День #4 #
Начинаешь входить в некий минимальный ад. Управляющие конструкции, рекурсии, символы, функции.

Навыки: Условия (if, else, for, while), символы и типы (char, int, ASCII), циклы, форматированный вывод, рекурсия, функции.

# 5. День #5 #
Начинается экзамен, совмещаем требования к этим 4 дням - вот это и будет на экзамене. На самом деле, максимально просто, главное не обосраться на том, чтобы запомнить ссылку exam.21-school.ru, как генерировать ssh ключ, как коммитить и пушить.

# 6. День #6 (Rush00) #
Шестой день - групповой проект pong.c.
Вам необходимо будет написать с такими же двумя калеками как и вы терминальный пошаговый пинг-понг, а если хотите дополнительные баллы - придется попотеть и использовать lncurses.
Из навыков хватит то же самое что делали на протяжении всех этих дней.

# 8. День #8 #
Восьмой день - пиздец подкрался незаметно! Указатели, массивы, ввод-вывод, сравнения, перебор, поиск.

Навыки: Указатели, Массивы, функции и параметры, строки, арифметика указателей, интерации и поиск, ввод-вывод.

# 9. День #9 #
Девятый день - сортировки, циклические сдвиги, работа с несколькими массивами и имитация длинной арифметики, память.

Навыки: Память (malloc, alloc, calloc, realloc, free, memcpy, memmove), сортировки (bubble sort, insertion sort, qsort), двумерные массивы, массивы указателей, массив цифр

# 10. День #10 #
Десятый день - указатели, динамическое выделение памяти, управление утечками, арифметика над матрицами и ручное рисование, можешь обернуться вокруг и увидишь как людей то на интенсиве уже меньше и меньше, потому что поплыли ребятки.

Выживает тот, кто не путает *p++ и (*p)++, кто может сделать matrix[i][j] через char *matrix = malloc(rows * cols).

Навыки: указатели и память (malloc, calloc, realloc, free, null), valgrind, free(p), двумерные массивы, qsort, printf. 

# 11. День #11 #
Одиннадцатый день — контрольная по матрицам: алгоритмы обхода, поиск шаблонов, принятие решений и скрытая линейная алгебра. Если ты не дружишь с двумерными массивами — тебя смоет первым же заданием.

Навыки: матрицы, обходы матриц, условия и фильтрация, СЛАУ, рекурсия, память.

# 12. День #12 #
Экзамен, где с тебя спросят за всю память, массивы, алгоримы и прочее с чем ты страдал всю вторую неделю.

# 13. День #13 (Rush01) #
Тринадцатый день - пишете групповой проект "Game Of Life", тут уже в априори используется ncurses, а о самой игре можете почитать в этих ваших интернетах.

# 15. День #15 #
Пятнадцатый день - достаточно простой, учитывая что на 2 неделе очень сильно надавили, 3 неделя кажется раем. Знакомитесь с модулями, библиотеками, как с ними работать, узнаете подробнее о makefile.

# 16. День #16 #
Шестнадцатый день - пишете свою библиотеку string и учитесь автотестам для них.

# 17. День #17 #
Нужно достаточно много математики, без математики - не выживаете. Что связано с СИ - то же самое что было до этого.

# 18. День #18 #
Восемнадцатый день - учат дописывать модульные программы.

# 19. День #19 #

Экзамен, все по старому, ничего не изменилось :)

# 20. День #20 (Rush02) #
Двадцатый день - вместе со своей командой вам необходимо научиться работать с графиками функции, задаваемыми произвольными выражениями. Используете алгоритм Дейкстры, в основном тут многие сдаются.

# 22. День #22 #
Работа с текстовыми файлами, чтение и вывод из них с помощью них и т.п, учат шифровать кодом цезаря, потом расшифровывать через него же, учат логгированию.

# 23. День #23 #
Учат замудренной сортировке

# 24. День #24 #
Выдается задача, где по сути необходимо написать свою базу данных.

# 25. День #25 #
Продолжаешь работу над тем, что было на 24 дне.

# 26. День #26 (Финальный экзамен) #
Финальное закрепление абсолютно всей информации, на самом деле не такой сложный, как можно подумать, сдать достаточно легко, если не сдался.
