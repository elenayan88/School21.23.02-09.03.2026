## 🎯 Конкретный план подготовки

### День 1: Командная строка + Git
**Утром (2-3 часа):**
- Изучить базовые команды: `ls`, `cd`, `pwd`, `mkdir`, `rm`, `cp`, `mv`
- Научиться работать с правами доступа: `chmod`, `chown`
- Попрактиковаться в навигации по файловой системе

**Вечером (1-2 часа):**
- Создать GitHub аккаунт
- Изучить `git clone`, `git add`, `git commit`, `git push`
- Настроить SSH ключи

### День 2: Основы C
**Утром (3-4 часа):**
- Синтаксис C: переменные, типы данных, операторы
- Условные конструкции: `if`, `else`, `switch`
- Циклы: `for`, `while`, `do-while`

**Вечером (2-3 часа):**
- Функции: объявление, вызов, параметры
- Массивы: одномерные, работа с элементами
- Строки: массивы символов, основные функции

### День 3: Практика
**Весь день (4-6 часов):**
- Решить 10-15 простых задач на Codewars
- Написать несколько программ:
  - Калькулятор
  - Программа для поиска максимума в массиве
  - Программа для подсчета символов в строке
- Попрактиковаться с компиляцией: `gcc -Wall -Wextra -Werror`

## 🔥 Экстренная подготовка (1 день)

Если у тебя всего один день:

1. **2 часа**: Базовые команды терминала
2. **1 час**: Git clone, add, commit, push
3. **3 часа**: Основы C (переменные, циклы, функции)
4. **2 часа**: Решение 5-7 простых задач
